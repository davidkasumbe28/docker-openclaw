
# Code of Conduct

Ce projet accueille toutes les personnes souhaitant contribuer de manière constructive.

## Comportements attendus

- Respecter les autres contributeurs.
- Accueillir les avis différents.
- Fournir des retours constructifs.
- Favoriser les échanges techniques.

## Comportements interdits

- Harcèlement.
- Discrimination.
- Attaques personnelles.
- Publication d'informations privées.
- Perturbation volontaire du projet.

Les maintainers peuvent modérer les contributions ne respectant pas ces règles.
