
# Security Policy

## Version concernée

Les recommandations de sécurité ciblent la version OpenClaw documentée dans ce repository.

## Signaler une vulnérabilité

Ne publiez pas de vulnérabilité dans une issue publique.

Utilisez GitHub Security Advisories pour contacter les maintainers de manière privée.

## Recommandations

- Protéger le fichier `.env`.
- Ne jamais publier les API keys.
- Utiliser un Gateway token aléatoire.
- Garder le Gateway sur localhost par défaut.
- Protéger les backups.
- Mettre à jour Docker Desktop.
- Tester régulièrement les procédures de Restore.
